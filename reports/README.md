# Reports

Read-only experiment reports served as MCP resources (`reports://{name}`).

The `.md` and `.json` files here are copied unchanged from the BERTurk project
(<https://github.com/SerpilUmayGedikli/BERTurk>, `reports/` at commit `7feffd2`).
The numbers were produced there, not re-measured in this repository. In those reports the
BERTurk fine-tuning runs are marked **NOT RUN**; only the TF-IDF baselines have results.

This README is not served as a resource.
